#7
O condicional presente para dar conselhos: <span lang="it">dovresti, potresti, sarebbe meglio</span>

#8
<span lang="it"><strong>Potresti</strong> togliere i colori al telefono.</span> → <span lang="it">potere</span> no condicional = um conselho gentil (você poderia): <span lang="it">potrei, potresti, potrebbe, potremmo, potreste, potrebbero</span>

#9
<span lang="it"><strong>Dovresti</strong> essere meno perfezionista.</span> → <span lang="it">dovresti</span> + infinitivo = um conselho mais forte (você deveria)

#10
<span lang="it"><strong>Sarebbe meglio</strong> decidere prima quando fare ogni cosa.</span> → <span lang="it">sarebbe meglio</span> (seria melhor) + infinitivo, <span lang="it">ti aiuterebbe, ti servirebbe</span>: o condicional deixa o conselho menos direto que o imperativo

#11
Experimente: transforme a ordem em um conselho com o condicional. <span lang="it"><em>Spegni il telefono! → Tu (potere) … spegnere il telefono. Dormi di più! → Tu (dovere) … dormire di più. Fai una pausa! → (essere) … meglio fare una pausa.</em></span>

O período hipotético: <span lang="it">se vibra, ci distrae · se spegnessi, lavoreresti · se non l’avessero interrotta, avrebbe finito</span>

#15
<span lang="it"><strong>Se</strong> il telefono <strong>vibra</strong>, la mente ci <strong>va</strong>.</span> → primeiro tipo (realidade): <span lang="it">se</span> + presente, depois presente ou futuro: algo que acontece de verdade

#16
<span lang="it"><strong>Se</strong> domani <strong>spegnessi</strong> le notifiche, forse ti <strong>stupiresti</strong>.</span> → segundo tipo (possibilidade): <span lang="it">se</span> + imperfeito do subjuntivo, depois condicional presente

#17
<span lang="it"><strong>Se</strong> nessuno l’<strong>avesse interrotta</strong>, l’<strong>avrebbe finita</strong> in un’ora.</span> → terceiro tipo (irrealidade no passado): <span lang="it">se</span> + mais-que-perfeito do subjuntivo, depois condicional composto

#23
