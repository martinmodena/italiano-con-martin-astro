#10
O imperfetto: <span lang="it">era, avevo, portavano</span>

#11
<span lang="it">Questa <strong>era</strong> la mia scuola. <strong>Avevo</strong> sei anni.</span> → <span lang="it">imperfetto</span> para descrever o passado: idade, lugares, como eram as coisas (<span lang="it">essere → ero, eri, era…</span>; <span lang="it">avere → avevo</span>)

#12
<span lang="it">A scuola tutti i bambini <strong>portavano</strong> il grembiule.</span> → <span lang="it">imperfetto</span> para os hábitos do passado: <span lang="it">-are → -avo, -avi, -ava, -avamo, -avate, -avano</span>

#13
<span lang="it">Ogni sera <strong>guardavamo</strong> Carosello.</span> → com <span lang="it">ogni sera, sempre, di solito</span> (toda noite, sempre, normalmente) usa-se o <span lang="it">imperfetto</span>; <span lang="it">-ere → -evo</span>, <span lang="it">-ire → -ivo</span>

#14
Experimente: escreva o verbo no imperfetto. <span lang="it"><em>Quando (essere) … piccolo, (abitare) … in campagna. Ogni estate (andare) … al mare con i nonni.</em></span>

#15
<span lang="it">il grembiule</span> = o guarda-pó, o avental escolar<br><span lang="it">il fiocco</span> = o laço<br><span lang="it">la pubblicità</span> = a propaganda, os comerciais<br><span lang="it">il compagno di banco</span> = o colega de carteira<br><span lang="it">la treccia</span> = a trança

O futuro simples: <span lang="it">prenderemo, andremo, sarà</span>

#26
<span lang="it">Venerdì mattina <strong>prenderemo</strong> il treno delle 7.10.</span> → futuro para os planos: <span lang="it">-are</span> e <span lang="it">-ere → -erò, -erai, -erà, -eremo, -erete, -eranno</span>; <span lang="it">-ire → -irò</span>

#27
<span lang="it">Allora non <strong>andremo</strong> a Venezia.</span> → futuro irregular: <span lang="it">andare → andrò, essere → sarò, avere → avrò, fare → farò</span>

#28
