Os verbos reflexivos: <span lang="it">si fermano, si aggrappano, si tengono</span>

#16
<span lang="it">Le formiche non <strong>si fermano</strong> e non tornano indietro.</span> → <span lang="it">fermarsi</span> (parar): <span lang="it">mi fermo, ti fermi, si ferma, ci fermiamo, vi fermate, si fermano</span>

#17
<span lang="it">La prima formica <strong>si aggrappa</strong> al bordo della foglia.</span> → o pronome vem antes do verbo, também com <span lang="it">non</span>: <span lang="it">non si fermano</span>, <span lang="it">si aggrappa</span> (em italiano o pronome nunca cai, mesmo quando no Brasil a gente diria só «para»)

#18
<span lang="it">Le formiche <strong>si tengono</strong> per le zampe e diventano un ponte.</span> → no plural, o pronome pode significar «um ao outro»: <span lang="it">si tengono, si toccano, si seguono</span>

#25
Os conectivos: <span lang="it">invece, però, infatti, quindi, anche se</span>

#26
<span lang="it">Sembra soltanto una bella fotografia. <strong>Invece</strong> è un piccolo problema di economia.</span> → <span lang="it">invece</span> = o contrário do que esperamos (na verdade, pelo contrário); <span lang="it">però</span> e <span lang="it">eppure</span> = mas, no entanto

#27
<span lang="it">Il ponte si è fermato, <strong>anche se</strong> poteva andare ancora più avanti.</span> → <span lang="it">anche se</span> + indicativo = mesmo que, embora: <span lang="it">anche se poteva</span>

#28
<span lang="it">Ogni formica che fa da ponte, <strong>infatti</strong>, non può portare cibo alla colonia.</span> → <span lang="it">infatti</span> confirma ou explica a frase anterior (de fato, com efeito); <span lang="it">quindi</span> e <span lang="it">perciò</span> = por isso, portanto

#29
Experimente: complete com invece, infatti, quindi ou anche se. <span lang="it"><em>Volevo prendere l’autobus, … sono andato a piedi. Era tardi, … ho preso un taxi. … era stanco, Marco è uscito con gli amici. Giulia è bravissima: … ha vinto la gara.</em></span>

#31
O presente do subjuntivo: <span lang="it">pensare che ci sia, senza che, in modo che</span>

#32
<span lang="it">Viene spontaneo pensare che <strong>ci sia</strong> un capo.</span> → <span lang="it">pensare che, sembrare che, sperare che</span> + subjuntivo: uma opinião ou uma esperança, não um fato certo (em português «acho que» pede o indicativo; em italiano, <span lang="it">penso che</span> pede o subjuntivo)

#33
<span lang="it">I ponti si sciolgono da soli, <strong>senza che</strong> nessuno <strong>dia</strong> l’ordine.</span> → <span lang="it">senza che</span> + subjuntivo quando os sujeitos são diferentes; com o mesmo sujeito se usa <span lang="it">senza</span> + infinitivo

#34
<span lang="it">Alcune operaie si sdraiano nelle buche, <strong>in modo che</strong> le altre <strong>corrano</strong> più veloci.</span> → <span lang="it">in modo che, perché</span> (= para que), <span lang="it">basta che, bisogna che</span> + subjuntivo
