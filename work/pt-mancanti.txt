#9 [pt/leituras/emma-as-fotos-dos-avos.html]
En casa de los abuelos de Chiara, Emma abre una caja de fotos viejas: niños vestidos todos iguales, la televisión en el bar, una regla que valía en toda Italia. Y en la última foto hay una sorpresa. Un relato A2 para aprender el imperfetto.

#10 [pt/leituras/emma-as-fotos-dos-avos.html]
El imperfetto: <span lang="it">era, avevo, portavano</span>

#11 [pt/leituras/emma-as-fotos-dos-avos.html]
<span lang="it">Questa <strong>era</strong> la mia scuola. <strong>Avevo</strong> sei anni.</span> → <span lang="it">imperfetto</span> para describir el pasado: edad, lugares, cómo eran las cosas (<span lang="it">essere → ero, eri, era…</span>; <span lang="it">avere → avevo</span>)

#12 [pt/leituras/emma-as-fotos-dos-avos.html]
<span lang="it">A scuola tutti i bambini <strong>portavano</strong> il grembiule.</span> → <span lang="it">imperfetto</span> para las costumbres del pasado: <span lang="it">-are → -avo, -avi, -ava, -avamo, -avate, -avano</span>

#13 [pt/leituras/emma-as-fotos-dos-avos.html]
<span lang="it">Ogni sera <strong>guardavamo</strong> Carosello.</span> → con <span lang="it">ogni sera, sempre, di solito</span> (cada noche, siempre, normalmente) se usa el <span lang="it">imperfetto</span>; <span lang="it">-ere → -evo</span>, <span lang="it">-ire → -ivo</span>

#14 [pt/leituras/emma-as-fotos-dos-avos.html]
Prueba tú: escribe el verbo en imperfetto. <span lang="it"><em>Quando (essere) … piccolo, (abitare) … in campagna. Ogni estate (andare) … al mare con i nonni.</em></span>

#15 [pt/leituras/emma-as-fotos-dos-avos.html]
<span lang="it">il grembiule</span> = el babi, la bata escolar<br><span lang="it">il fiocco</span> = el lazo<br><span lang="it">la pubblicità</span> = la publicidad, los anuncios<br><span lang="it">il compagno di banco</span> = el compañero de pupitre<br><span lang="it">la treccia</span> = la trenza

El futuro simple: <span lang="it">prenderemo, andremo, sarà</span>

#26 [pt/leituras/emma-o-plano-perfeito.html]
<span lang="it">Venerdì mattina <strong>prenderemo</strong> il treno delle 7.10.</span> → futuro para los planes: <span lang="it">-are</span> y <span lang="it">-ere → -erò, -erai, -erà, -eremo, -erete, -eranno</span>; <span lang="it">-ire → -irò</span>

#27 [pt/leituras/emma-o-plano-perfeito.html]
<span lang="it">Allora non <strong>andremo</strong> a Venezia.</span> → futuro irregular: <span lang="it">andare → andrò, essere → sarò, avere → avrò, fare → farò</span>

#28 [pt/leituras/emma-o-plano-perfeito.html]
<span lang="it">– <strong>Sarà</strong> in ritardo, – risponde Chiara.</span> → futuro para una suposición sobre el presente: <span lang="it">sarà in ritardo</span> = probablemente llega tarde
