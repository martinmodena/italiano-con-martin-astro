Cinque vignette sono riusate dalla pagina inglese, perché la parola tedesca inganna allo stesso modo: _camera_ (_Kamera_), _cantina_ (_Kantine_), _magazzino_ (_Magazin_), _confetti_ (_Konfetti_), _caldo_ (_kalt_).
