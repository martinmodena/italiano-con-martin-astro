Nasıl oluşur?

Şimdiki mükemmel şu şekilde oluşturulur: sahip olmak o olmak şimdiki zaman + geçmiş katılımcıda.

VerboParticipioEsempio
parlareparlatoHo parlato con Maria.
crederecredutoAbbiamo creduto alla storia.
dormiredormitoHai dormito bene?
andareandatoSono andato a Roma.

Formül: Bende var / sende / var / biz / sende / var + katılımcı veya ben / sen / o / biz / sen / ben + katılımcıyım.
