イタリア語の進行形：stare + ジェルンディオ

「いま〜している」と言うための形です：sto mangiando（食べているところ）、lui sta lavorando（彼は働いている）。このレッスンでは、ジェルンディオの作り方、不規則な形、使うときと使わないとき、stavo + ジェルンディオ、stare per + 不定詞、30問の練習問題を学びます。

作り方：stare + ジェルンディオ

動詞 stare の現在形と、動詞のジェルンディオを使います。stare は人称によって変わりますが、ジェルンディオは決して変わりません。

人称stare例
iostoSto parlando al telefono.
tustaiStai leggendo un libro?
lui / leistaIl bambino sta dormendo.
noistiamoStiamo mangiando.
voistateState scrivendo un’email?
lorostannoStanno lavorando.
不定詞ジェルンディオ例
parlare (-are)parlando (-ando)Sto parlando con Anna.
leggere (-ere)leggendo (-endo)Sto leggendo il giornale.
dormire (-ire)dormendo (-endo)Sto dormendo poco.
finire (-isc-)finendo (-endo)Sto finendo i compiti.

-ere と -ire の動詞は同じ語尾 -endo になります。finire や capire のような動詞は -isc- もなくなります：finendo、capendo。

代名詞はどこに置く？ stare の前か、ジェルンディオのうしろにつけます：lo sto facendo = sto facendolo（それをしているところ）、mi sto lavando = sto lavandomi（体を洗っているところ）。前に置く形のほうがずっとよく使われます。

不規則なジェルンディオ

不規則なジェルンディオは少ないですが、どれもよく使う動詞です。

不定詞ジェルンディオ例
fare (facevo)facendoSto facendo la doccia.
dire (dicevo)dicendoChe cosa stai dicendo?
bere (bevevo)bevendoSto bevendo un caffè.
tradurre (traducevo)traducendoSto traducendo una lettera.
porre (ponevo)ponendoTi sto ponendo una domanda.

半過去を使ったコツ。不規則なジェルンディオは半過去と同じように作ります：facevo → facendo、dicevo → dicendo、bevevo → bevendo、traducevo → traducendo。半過去を知っていれば、ジェルンディオもわかります。

使うとき（と使わないとき）

stare + ジェルンディオは、ある動作がちょうどいま進行中であることを表します。ただ、日本語の「〜している」ほど広くは使わず、多くの場合は現在形で十分です。

ちょうどいま
Non posso rispondere: sto guidando.
電話で
Che cosa stai facendo? Sto cucinando.
いま続いている期間
In questi mesi sto studiando il tedesco.
現在形で十分なことが多い
Che fai stasera? Esco con Anna.
習慣：現在形
Lavoro in banca da dieci anni.
未来の予定：現在形
Domani parto per Roma.

未来には使いません。予定を言うときは domani parto（明日出発します）と言い、domani sto partendo とは言いません。

状態を表す動詞は現在形のままです：so（知っている）、voglio（ほしい）、mi piace（好きだ）、sono、ho。日本語では「知っている」と言いますが、イタリア語で sto sapendo や sto essendo とは決して言いません。

過去では：stavo + ジェルンディオ

stare を半過去にすると、過去に進行中だった動作を表します。passato prossimo の別の動作で中断されることがよくあります：「寝ていたら…」。

人称stare例
iostavoStavo dormendo.
tustaviStavi uscendo?
lui / leistavaStava piovendo.
noistavamoStavamo cenando.
voistavateStavate guardando la TV?
lorostavanoStavano parlando di te.
中断された動作
Stavo dormendo quando è suonato il telefono.
mentre（〜しているあいだに）といっしょに
Mentre stavamo cenando, è andata via la luce.
そのときの天気
Quando sono uscito stava piovendo.

stavo dormendo と dormivo、どちら？ どちらも正しい言い方です：dormivo quando è suonato il telefono。stavo + ジェルンディオを使うと、動作が目の前で起きているように、より生き生きと感じられます。

stare per + 不定詞：sto per uscire

混同しないでください：stare per + 不定詞は、ある動作がもうすぐ始まることを表し、「いまにも〜しようとしている」という意味です。

もうすぐ
Sto per uscire: ti chiamo dopo.
過去で
Stavo per addormentarmi quando sei arrivato.
危ないとき
Attento, il bicchiere sta per cadere!
ちがい
Sto uscendo adesso. Sto per uscire tra un minuto.

sto uscendo と sto per uscire、どちら？ sto uscendo：もう玄関にいる。sto per uscire：もうすぐ出かけるけれど、まだ家にいる。

よくある間違い

誤： Io sto mangiare. 正： Io sto mangiando.
誤： Sono mangiando. 正： Sto mangiando.
誤： Sto leggiando. 正： Sto leggendo.
誤： Sto fando i compiti. 正： Sto facendo i compiti.
誤： Stanno mangiandi. 正： Stanno mangiando.
誤： Domani sto partendo per Roma. 正： Domani parto per Roma.
誤： Sto sapendo la risposta. 正： So la risposta.
誤： Sto essendo stanco. 正： Sono stanco.
