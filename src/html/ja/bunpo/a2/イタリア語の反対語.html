イタリア語の反対語：s-、dis-、in-

Vantaggioとsvantaggio（長所・短所）、onestoとdisonesto、possibileとimpossibile：日常でよく使う反対語のペア、単語を反対の意味に変える接頭辞（s-, dis-, in-, im-, il-, ir-）、caricareとscaricareのような動詞、そしてscegliereやdispiacereのような落とし穴。練習問題30問つき。

日常でよく使うペア

反対語の多くは接頭辞のない、まったく別の単語です。ペアで覚えましょう。新しい形容詞や動詞を覚えたら、すぐにその反対語も調べてみましょう。

形容詞
grande / piccolo · bello / brutto · caro / economico · facile / difficile · pieno / vuoto
動詞
aprire / chiudere · accendere / spegnere · comprare / vendere · entrare / uscire · ricordare / dimenticare
副詞
sempre / mai · presto / tardi · prima / dopo · sopra / sotto · dentro / fuori
代名詞
tutto / niente · qualcuno / nessuno · qualcosa / niente

Nessuno, niente、maiは動詞の前にnonが必要です。non c’è nessuno（誰もいない）、non ho capito niente（何もわからなかった）、non vado mai al cinema（映画には一度も行かない）。日本語の「誰も〜ない」と同じで、否定が二つあっても打ち消し合いません。

接頭辞s-, dis-, in-

日本語では「不・非・無・未」を前につけて反対の意味を作ります（不可能、不便、非合法、無名）。イタリア語も同じように、単語の前に接頭辞をつけます。よく使うのはs-、dis-、in-の三つです。p, b, mの前ではin-がim-に、lの前ではil-に、rの前ではir-になります。

接頭辞例
s-vantaggio → svantaggio · fortuna → sfortuna · comodo → scomodo · contento → scontento · conosciuto → sconosciuto · piacevole → spiacevole
dis-onesto → disonesto · ordine → disordine · accordo → disaccordo · occupato → disoccupato · attento → disattento
in-utile → inutile · felice → infelice · capace → incapace · sicuro → insicuro · credibile → incredibile
im- (+ p, b, m)possibile → impossibile · paziente → impaziente · probabile → improbabile · maturo → immaturo
il- (+ l)legale → illegale · logico → illogico
ir- (+ r)regolare → irregolare · responsabile → irresponsabile · reale → irreale
a- · anti-tipico → atipico · sociale → asociale · simpatico → antipatico

選び方のコツ：s-は子音の前にだけつきます（s-comodo ＝ 不便な、s-fortuna ＝ 不運）。母音の前ではdis-かin-を使います（dis-onesto ＝ 不正直な、in-utile ＝ 無用な）。sonestoという単語はありません。それ以外に決まりはないので、単語ごとに接頭辞と一緒に覚えましょう。

接頭辞は単語のほかの部分を変えません。性・数の一致はそのままで（disonesto, disonesta, disonesti）、副詞の作り方も同じです（sfortunatamente ＝ 残念ながら）。

反対語：日本語との比較

日本語は「不・非・無・未」を前につけて反対語を作ります。イタリア語も前に接頭辞をつけますが、使うのはin-、s-、dis-の三つで、どれを使うかは単語ごとに決まっています。

日本語イタリア語
不幸なinfelice
不便な、居心地が悪いscomodo
見知らぬ、無名のsconosciuto
不正直なdisonesto
不可能なimpossibile
荷物を降ろす、ロックを解除するscaricare, sbloccare
  • 「不」がいつもin-になるわけではありません：不便 → scomodo（s-）、不正直 → disonesto（dis-）。
  • 日本語では別の動詞を使うところ（積む／降ろす）を、イタリア語は同じ動詞に接頭辞をつけて表します：caricare / scaricare。
  • カタカナ語の「デメリット」はlo svantaggioです。s＋子音で始まるので冠詞はloになります。

s-とdis-のつく動詞

多くの動詞もs-やdis-で反対の意味になります。日本語では別の動詞を使うことが多いので注意しましょう。積む → 降ろす（caricare → scaricare）、ロックする → ロックを解除する（bloccare → sbloccare）。

Caricare / scaricare：積む・荷物を降ろす
Carico la lavatrice. · Scarico la lavatrice. · Scarico una app.
Bloccare / sbloccare：ロックする・ロックを解除する
Il telefono si è bloccato. · Come sblocco il telefono?
Collegare / scollegare：接続する・接続を切る
Collega il computer alla stampante. · Scollega il cavo.
Attaccare / staccare：貼る、差し込む・はがす、抜く
Attacco una foto al frigo. · Stacco la spina.
Montare / smontare：組み立てる・分解する
Monto il letto nuovo. · Smonto il vecchio armadio.
Fare / disfare：（スーツケースに）荷物を詰める・荷ほどきする
Faccio la valigia. · Disfo la valigia.
Coprire / scoprire：覆う・覆いを取る
Copro il bambino. · Il bambino si scopre di notte. · Ho scoperto un bel ristorante.

もう一つの意味がある動詞：scaricareはインターネットから「ダウンロードする」という意味でも使います（scaricare una app）。scoprireは「発見する」という意味にもなります（ho scoperto un bel ristorante）。

落とし穴

注意：s-、dis-、in-で始まる単語がすべて反対語というわけではありません。

反対語ではないs-
scegliere · spiegare · sbagliare · scrivere · studiare
Dispiacereは「好きではない」ではない
Mi dispiace, non posso venire. · Questo film non mi piace.
Infiammabile：燃えます！
Attenzione: la benzina è infiammabile!
接頭辞のない反対語
interessante / noioso · caro / economico · buono / cattivo · vero / falso
nonを使うと、より丁寧
Non è facile. · Non è bellissimo. · Non è il massimo.

Mi dispiaceは「残念です、すみません」という意味です。mi piaceの反対はnon mi piaceです。Infiammabileは「燃えやすい、可燃性の」という意味で、このin-は否定ではありません。またdisinteressanteという単語はなく、「つまらない」はnoiosoです。丁寧に言いたいとき、イタリア人はよくnon＋肯定の言葉を使います。è bruttoの代わりにnon è bellissimoと言うのは、日本語の「あまり好きじゃない」に似ています。

日本語話者によくある間違い

誤：È inpossibile. 正：È impossibile.
p の前では in- が im- になります。
誤：Ho un svantaggio. 正：Ho uno svantaggio.
s＋子音で始まる名詞の前では不定冠詞は uno。
誤：Il film è disinteressante. 正：Il film è noioso.
「つまらない」は接頭辞では作れません：noioso。
誤：Mi dispiace il caffè. 正：Non mi piace il caffè.
Mi dispiace は「残念です」。「好きではない」は non mi piace。
