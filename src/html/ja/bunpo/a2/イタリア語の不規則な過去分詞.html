イタリア語の不規則な過去分詞

たくさんの動詞も、パターンはわずか

不規則な過去分詞のほとんどは -ere 動詞から来ています。一つずつ覚える必要はありません。グループごとに形が似ているからです。prendere が preso になると知っていれば、accendere → acceso、spendere → speso もわかります。

語尾例
-ttofare → fatto, scrivere → scritto, leggere → letto
-soprendere → preso, chiudere → chiuso, decidere → deciso
-ssomettere → messo, succedere → successo, discutere → discusso
-stovedere → visto, chiedere → chiesto, rispondere → risposto
-rtoaprire → aperto, offrire → offerto, morire → morto
-ntovincere → vinto, spegnere → spento, piangere → pianto
-ltoscegliere → scelto, togliere → tolto, risolvere → risolto
-urre → -ottotradurre → tradotto, produrre → prodotto
-orre → -ostoporre → posto, proporre → proposto
-arre → -attotrarre → tratto, distrarre → distratto

-ere 動詞がすべて不規則なわけではありません。 credere → creduto、vendere → venduto、ricevere → ricevuto、ripetere → ripetuto、cadere → caduto は規則どおりです。

二つの形をもつ動詞もあります。 perdere → perso または perduto、vedere → visto または veduto。ふだん使うのは最初の形です。

完全な一覧

それぞれの動詞について、過去分詞、passato prossimo の助動詞、例文を載せています。助動詞が essere のときは過去分詞の語尾が一致します：sono rimasta、siamo nati。

tradurre, porre, trarre：なぜ tradotto？

tradurre、porre、trarre は変わった形に見えますが、ひみつは簡単です。不定詞が短くなっているのです。tradurre の後ろには古い形 traducere があります。だから io traduco、ho tradotto と言うのです。fare（facere）、dire（dicere）、bere（bevere）も同じです。

不定詞古い形現在過去分詞
farefacereio facciofatto
diredicereio dicodetto
berebevereio bevobevuto
tradurretraducereio traducotradotto
porreponereio pongoposto
trarretraereio traggotratto
-urre 動詞はすべて → -otto
tradurre, produrre, ridurre, condurre, introdurre, sedurre → tradotto, prodotto, ridotto…
-orre 動詞はすべて → -osto
porre, proporre, comporre, esporre, opporre, supporre → posto, proposto, composto…
-arre 動詞はすべて → -atto
trarre, attrarre, distrarre, sottrarre → tratto, attratto, distratto…
ほかの時制では長い形が戻ってくる
traduco, traducevo, ho tradotto · propongo, proponevo, ho proposto

新しい -urre 動詞に出会ったら？ 調べる必要はありません：dedurre → dedotto、sedurre → sedotto。-orre（imporre → imposto）と -arre（contrarre → contratto）も同じです。

複合動詞

ほかの動詞からできた動詞は、元の動詞の過去分詞をもちます。prendere → preso を知っていれば、sorprendere → sorpreso、comprendere → compreso もわかります。

元の動詞複合動詞
prendere → presosorpreso, compreso, ripreso, appreso
mettere → messopromesso, permesso, smesso, ammesso
scrivere → scrittodescritto, iscritto, riscritto
fare → fattorifatto, soddisfatto
dire → dettocontraddetto, predetto
vedere → vistorivisto, previsto
venire → venutoavvenuto, intervenuto, svenuto
tenere → tenutoottenuto, mantenuto, trattenuto
porre → postoproposto, composto, esposto
trarre → trattoattratto, distratto, sottratto

見かけだけの複合動詞に注意。 本当に同じ動詞でなければいけません。spendere → speso は -so のパターンですが、prendere から来たわけではありません。

助動詞は変わることがあります。 venire は essere、avvenire も同じ（è avvenuto）ですが、prevenire は avere をとります（ho prevenuto un errore）。

よくある間違い

誤： Ho prenduto il treno. 正： Ho preso il treno.
誤： Ho aprito la porta. 正： Ho aperto la porta.
誤： Ho scrivuto una lettera. 正： Ho scritto una lettera.
誤： Ho traduciuto il testo. 正： Ho tradotto il testo.
誤： Ho metteto il sale. 正： Ho messo il sale.
誤： Ho chieduto un caffè. 正： Ho chiesto un caffè.
誤： Sono nascuto a Roma. 正： Sono nato a Roma.
誤： Ho vivuto a Londra. 正： Ho vissuto a Londra.
誤： Ho deciduto di partire. 正： Ho deciso di partire.
