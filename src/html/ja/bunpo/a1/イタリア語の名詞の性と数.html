文法A1

イタリア語の名詞の性と数

男性、女性、単数、複数を認識することを学びます。

基本的なルール

ファイナル通常複数形
-o男性的な-i
-aフェミニンな-e
-e男性的か女性的か-i
本o → 本i
家a → 家々e
レストランe → レストランi
夜e → 夜i

例外に注意してください

ラ・マーノ→手
問題 → 問題
写真 → 写真
コーヒー → コーヒー

強調された母音または子音で終わる名詞は、複数形でも変化しないことがよくあります。 都市→都市, バー → バー.

よくある間違い

❌家
✓ 住宅
❌ 予約します
✓ 本
❌問題
✓ 問題点
❌コーヒー
✓ コーヒー
