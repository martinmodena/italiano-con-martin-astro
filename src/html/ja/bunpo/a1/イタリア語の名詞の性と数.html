文法A1

イタリア語の名詞の性と数

男性、女性、単数、複数を認識することを学びます。

基本的なルール

語尾たいてい複数
-o男性-i
-a女性-e
-e男性または女性-i
il libro → i libri
la casa → le case
il ristorante → i ristoranti
la notte → le notti

例外に注意してください

la mano → le mani
il problema → i problemi
la foto → le foto
il caffè → i caffè

強調された母音または子音で終わる名詞は、複数形でも変化しないことがよくあります。 la città → le città, il bar → i bar.

よくある間違い

❌ i casa
✓ le case
❌ le libro
✓ i libri
❌ i problemo
✓ i problemi
❌ le caffè
✓ i caffè
