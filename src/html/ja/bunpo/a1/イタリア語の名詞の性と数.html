イタリア語の名詞の性と数：il libro, i libri

Il libro, la casa, i libri, le case：イタリア語の名詞はすべて男性か女性で、複数になると形が変わります。日本語にはない考え方ですが、ルールはかんたんです。母音のルール、複数形、人を表す名詞の男性形と女性形、変わらない名詞（la città, il bar）、例外（il problema, la mano, le uova）。練習問題30問つき。

男性名詞？女性名詞？

イタリア語ではすべての名詞が男性か女性です。物も同じです：il libro（本）は男性、la casa（家）は女性。日本語にはない区別ですが、ほとんどの場合、最後の文字でわかります。

-o：ほとんど男性
il libro · il gatto · il treno
-a：ほとんど女性
la casa · la pizza · la scuola
-e：男性か女性
il pane · il fiore · la chiave · la notte
役に立つ語尾：-zione, -tà は女性、-ore は男性
la stazione · la città · il colore · il dottore

名詞はいつも冠詞といっしょに覚えましょう：pane ではなく il pane（パン）、chiave ではなく la chiave（かぎ）。-e で終わる名詞は、それ以外に性を知る方法がありません。

名詞の性と数：日本語とのちがい

日本語の名詞には性も複数形もありません。イタリア語では名詞がすべて 男性か女性 で、数が2つ以上なら形を変えます。

日本語イタリア語
本（1冊）il libro
本（2冊）i libri
家（たくさん）le case
りんご3つtre mele
コーヒー2杯due caffè
  • 数が2つ以上なら 必ず複数形：due libri（due libro はまちがい）。
  • 日本語の「〜冊、〜杯」のような数え方の言葉はいりません：tre mele。
  • 名詞は冠詞といっしょに覚えると、性も単数・複数もわかります：il libro / i libri。

複数形

複数になると最後の母音が変わります。日本語では「本が2冊」でも「本」は変わりませんが、イタリア語では必ず変えます：un libro（本1冊）、due libri（本2冊）。

単数複数例
-o-iil libro → i libri
-a-ela casa → le case
-e-iil fiore → i fiori · la chiave → le chiavi
-ca · -ga-che · -ghel’amica → le amiche · la riga → le righe
-co · -go-ci · -chi · -ghil’amico → gli amici · il gioco → i giochi

冠詞も変わります：il → i、lo → gli、la → le、l’ → gli（男性）または le（女性）。すべての形は定冠詞のレッスンにあります。-ca, -ga では、かたい音を残すために h が入ります：amica → amiche。-co, -go もたいていそうです：gioco → giochi。ただし amico → amici、medico → medici。

人：男性形と女性形

人（と多くの動物）には、男性形と女性形があることがよくあります。日本語の「学生」はだれにでも使えますが、イタリア語では変わります。

男性女性
il ragazzola ragazza
l’amicol’amica
il signorela signora
lo studentela studentessa
il dottorela dottoressa
l’attorel’attrice
il cantantela cantante
il turistala turista

いちばん多いのは -o → -a です：il ragazzo, la ragazza（男の子、女の子）。-essa（la studentessa, la dottoressa）や -trice（l’attrice）をつける名詞もあります。-ante、-ista で終わる名詞は変わらず、冠詞だけが変わります：il cantante, la cantante（歌手）。

変わらない名詞

単数と複数で同じ形の名詞もあります。冠詞だけが変わります。

最後の母音にアクセント記号がある
la città → le città · il caffè → i caffè
外来語
il bar → i bar · lo sport → gli sport
短くした言葉
la foto → le foto · la bici → le bici · il cinema → i cinema

単数か複数か、どうやってわかる？冠詞を見ましょう：la città（町1つ）、le città（町がいくつも）。短くした言葉は、もとの長い言葉の性のままです：la foto（la fotografia）、la bici（la bicicletta）、il cinema（il cinematografo）。

例外

ルールどおりでない言葉は少しだけですが、毎日使う言葉です。すぐに覚えておきましょう。

-a で終わる男性名詞：複数は -i
il problema → i problemi · il programma → i programmi
-o で終わる女性名詞
la mano → le mani · la radio → le radio
まったくちがう複数形
l’uomo → gli uomini
単数は男性、複数は女性
l’uovo → le uova · il braccio → le braccia
la gente：単数
la gente è simpatica · le persone sono simpatiche

-a で終わる男性名詞の多くはギリシャ語から来ていて -ma で終わります：il problema, il programma, il tema, il clima。体の一部には -a で終わる女性の複数形をもつものがあります：le braccia, le dita, le ginocchia。la gente（人々）は単数です：la gente è simpatica。形容詞も名詞に合わせて変わります。形容詞のレッスンを見てください。

日本語話者によくある間違い

誤：due libro 正：due libri
2つ以上なら 複数形：libri。
誤：libro 正：il libro
名詞は 冠詞 といっしょに使います：il libro。
誤：i casa 正：le case
女性の複数は le と -e。
誤：la problema 正：il problema
problema は 男性名詞です。
誤：le cittàe 正：le città
アクセント記号で終わる名詞は複数でも変わりません。
