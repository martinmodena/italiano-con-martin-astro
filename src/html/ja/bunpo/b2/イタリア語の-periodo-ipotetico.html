文法B2

イタリア語の periodo ipotetico

se を使った文を作りましょう：現実、可能性、想像の状況。

18分10 の演習レベルB2
種類可能非現実練習問題

主な3つのタイプ

種類構造例
現実se + presente, presente/futuroSe studi, migliori.
可能se + congiuntivo imperfetto, condizionale presenteSe studiassi di più, parleresti meglio.
過去の非現実の仮定se + congiuntivo trapassato, condizionale passatoSe avessi studiato, avresti superato l'esame.

可能な仮定・想像の仮定

se のあとに congiuntivo imperfetto、結果の部分に condizionale presente を使います。

Se avessi tempo, leggerei di più.
Se fossi in Italia, parlerei italiano ogni giorno.
Se potessi, farei una lezione con Martin.
Se studiassimo insieme, sarebbe più facile.

過去についての非現実の仮定

実際には起こらなかったことを話すときは、congiuntivo trapassato と condizionale passato を使います。

Se avessi saputo...
Se avessi saputo la risposta, l'avrei detta.
Se fossi partito...
Se fossi partito prima, sarei arrivato in tempo.
avere の場合
avrei mangiato, avresti visto.
essere の場合
sarei andato, saresti arrivata.

よくある間違い

誤：se avrei tempo. 正：se avessi tempo.
誤：se sarei ricco. 正：se fossi ricco.
誤：se studiavo, parlerei. 正：se studiassi, parlerei.
誤：se avrei studiato. 正：se avessi studiato.
