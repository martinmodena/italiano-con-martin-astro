Los tres tipos principales

TipoEstructuraEjemplo
Realse + presente, presente/futuroSe studi, migliori.
Posiblese + congiuntivo imperfetto, condizionale presenteSe studiassi di più, parleresti meglio.
Irreal en el pasadose + congiuntivo trapassato, condizionale passatoSe avessi studiato, avresti superato l'esame.

Hipótesis posible o imaginaria

Usamos el congiuntivo imperfetto después de se y el condizionale presente en la consecuencia.

Se avessi tempo, leggerei di più.
Se fossi in Italia, parlerei italiano ogni giorno.
Se potessi, farei una lezione con Martin.
Se studiassimo insieme, sarebbe più facile.

Hipótesis irreal en el pasado

Cuando hablamos de algo que no sucedió, usamos el congiuntivo trapassato y el condizionale passato.

Se avessi saputo...
Se avessi saputo la risposta, l'avrei detta.
Se fossi partito...
Se fossi partito prima, sarei arrivato in tempo.
Con avere
avrei mangiato, avresti visto.
Con essere
sarei andato, saresti arrivata.

Errores comunes

Incorrecto: se avrei tempo. Correcto: se avessi tempo.
Incorrecto: se sarei ricco. Correcto: se fossi ricco.
Incorrecto: se studiavo, parlerei. Correcto: se studiassi, parlerei.
Incorrecto: se avrei studiato. Correcto: se avessi studiato.
