Pocos modelos para muchos verbos

Casi todos los participios irregulares vienen de verbos en -ere. No hay que aprenderlos uno por uno: se parecen por grupos. Si sabes que prendere da preso, también sabes accendere → acceso y spendere → speso.

TerminaciónEjemplo
-ttofare → fatto, scrivere → scritto, leggere → letto
-soprendere → preso, chiudere → chiuso, decidere → deciso
-ssomettere → messo, succedere → successo, discutere → discusso
-stovedere → visto, chiedere → chiesto, rispondere → risposto
-rtoaprire → aperto, offrire → offerto, morire → morto
-ntovincere → vinto, spegnere → spento, piangere → pianto
-ltoscegliere → scelto, togliere → tolto, risolvere → risolto
-urre → -ottotradurre → tradotto, produrre → prodotto
-orre → -ostoporre → posto, proporre → proposto
-arre → -attotrarre → tratto, distrarre → distratto

No todos los verbos en -ere son irregulares. Credere → creduto, vendere → venduto, ricevere → ricevuto, ripetere → ripetuto, cadere → caduto siguen la regla.

Algunos verbos tienen dos formas. Perdere → perso o perduto, vedere → visto o veduto: la primera forma es la de todos los días.

Tradurre, porre, trarre: ¿por qué tradotto?

Tradurre, porre y trarre parecen raros, pero el secreto es sencillo: el infinitivo está acortado. Detrás de tradurre está el antiguo traducere: por eso decimos io traduco y ho tradotto. Lo mismo pasa con fare (facere), dire (dicere) y bere (bevere).

InfinitivoForma antiguaPresenteParticipio
farefacereio facciofatto
diredicereio dicodetto
berebevereio bevobevuto
tradurretraducereio traducotradotto
porreponereio pongoposto
trarretraereio traggotratto
Todos los verbos en -urre → -otto
tradurre, produrre, ridurre, condurre, introdurre, sedurre → tradotto, prodotto, ridotto…
Todos los verbos en -orre → -osto
porre, proporre, comporre, esporre, opporre, supporre → posto, proposto, composto…
Todos los verbos en -arre → -atto
trarre, attrarre, distrarre, sottrarre → tratto, attratto, distratto…
En los otros tiempos vuelve la forma larga
traduco, traducevo, ho tradotto · propongo, proponevo, ho proposto

¿Un verbo nuevo en -urre? No hace falta buscarlo: dedurre → dedotto, sedurre → sedotto. Lo mismo vale para -orre (imporre → imposto) y -arre (contrarre → contratto).

Los verbos compuestos

Un verbo formado a partir de otro tiene el participio del verbo base: si sabes prendere → preso, también sabes sorprendere → sorpreso y comprendere → compreso.

Verbo baseCompuestos
prendere → presosorpreso, compreso, ripreso, appreso
mettere → messopromesso, permesso, smesso, ammesso
scrivere → scrittodescritto, iscritto, riscritto
fare → fattorifatto, soddisfatto
dire → dettocontraddetto, predetto
vedere → vistorivisto, previsto
venire → venutoavvenuto, intervenuto, svenuto
tenere → tenutoottenuto, mantenuto, trattenuto
porre → postoproposto, composto, esposto
trarre → trattoattratto, distratto, sottratto

Cuidado con los falsos compuestos. El verbo tiene que ser realmente el mismo: spendere → speso sigue el modelo en -so, pero no viene de prendere.

El auxiliar puede cambiar. Venire lleva essere y también avvenire (è avvenuto), pero prevenire lleva avere (ho prevenuto un errore).

Incorrecto: Ho aprito la porta. Correcto: Ho aperto la porta.
Incorrecto: Ho scrivuto una lettera. Correcto: Ho scritto una lettera.
Incorrecto: Ho traduciuto il testo. Correcto: Ho tradotto il testo.

Incorrecto: Ho chieduto un caffè. Correcto: Ho chiesto un caffè.
