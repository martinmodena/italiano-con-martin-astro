Možná nebo imaginární hypotéza

Po se používáme congiuntivo imperfetto a v důsledku condizionale presente.

Se avessi tempo, leggerei di più.
Se fossi in Italia, parlerei italiano ogni giorno.
Se potessi, farei una lezione con Martin.
Se studiassimo insieme, sarebbe più facile.

Nereálná hypotéza v minulosti

Když mluvíme o něčem, co se nestalo, používáme congiuntivo trapassato a condizionale passato.

Se avessi saputo...
Se avessi saputo la risposta, l'avrei detta.
Se fossi partito...
Se fossi partito prima, sarei arrivato in tempo.
S avere
avrei mangiato, avresti visto.
S essere
sarei andato, saresti arrivata.

Časté chyby

Špatně: se avrei tempo. Správně: se avessi tempo.
Špatně: se sarei ricco. Správně: se fossi ricco.
Špatně: se studiavo, parlerei. Správně: se studiassi, parlerei.
Špatně: se avrei studiato. Správně: se avessi studiato.
