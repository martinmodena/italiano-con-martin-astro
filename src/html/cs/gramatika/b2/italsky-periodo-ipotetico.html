TypStrukturaPříklad

Možná nebo imaginární hypotéza

Nedokonalý konjunktiv pak použijeme se a kondicionál přítomný v důsledku.

Se avessi tempo, leggerei di più.
Se fossi in Italia, parlerei italiano ogni giorno.
Se potessi, farei una lezione con Martin.
Se studiassimo insieme, sarebbe più facile.

Nereálná hypotéza v minulosti

Když mluvíme o něčem, co se nestalo, používáme minulý konjunktiv a minulý podmiňovací způsob.

Se avessi saputo...
Se avessi saputo la risposta, l'avrei detta.
Se fossi partito...
Se fossi partito prima, sarei arrivato in tempo.
Se slovesem avere
Já bych jedl, viděl bys.
Se slovesem essere
Já bych šel, ty bys přijel.

Časté chyby

Špatně: se avrei tempo.Corretto: se avessi tempo.
Špatně: se sarei ricco.Corretto: se fossi ricco.
Špatně: se studiavo, parlerei.Corretto: se studiassi, parlerei.
Špatně: se avrei studiato.Corretto: se avessi studiato.
