Comment se forme-t-il ?

Pour beaucoup de verbes, on enlève la fin de l’infinitif et on ajoute les terminaisons du futur.

PersonneParlarePrenderePartire
ioparleròprenderòpartirò
tuparleraiprenderaipartirai
lui / leiparleràprenderàpartirà
noiparleremoprenderemopartiremo
voiparlereteprenderetepartirete
loroparlerannoprenderannopartiranno

Note : dans les verbes en -are, le a devient e : parlare → parlerò, mangiare → mangerò.

Quand l'utilisons-nous ?

Projets
Domani visiterò il centro.
Prévisions
Secondo me pioverà.
Promesses
Ti chiamerò stasera.
Hypothèses sur le présent
Sarà a casa? = forse è a casa.

Futurs irréguliers fréquents

InfinitifRadical du futurExemple
esseresar-sarò, sarai, sarà
avereavr-avrò, avrai, avrà

farefar-farò, farai, farà
venireverr-verrò, verrai, verrà
poterepotr-potrò, potrai, potrà

Erreurs courantes

Incorrect : io parleraio. Correct : io parlerò.
Incorrect : domani vado a Roma, sempre. Correct : domani andrò a Roma.
Incorrect : loro partirà. Correct : loro partiranno.
Incorrect : io andarò. Correct : io andrò.
