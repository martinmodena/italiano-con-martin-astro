Grammaire A1

Genre et nombre des noms italiens

Apprenez à reconnaître le masculin, le féminin, le singulier et le pluriel.

La règle de base

FinaleHabituellementPluriel
-omasculin-je
-unféminin-e
-emasculin ou féminin-je
le livreo → les livresi
la maisona → les maisonse
le restaurante → les restaurantsi
la nuite → les nuitsi

Attention aux exceptions

la mano → mains
le problème → les problèmes
la photo → les photos
café → cafés

Les noms qui se terminent par une voyelle ou une consonne accentuée ne changent souvent pas au pluriel : la ville → les villes, le bar → les bars.

Erreurs courantes

❌ la maison
✓ maisons
❌ Je les réserve
✓ livres
❌ les problèmes
✓ les problèmes
❌ cafés
✓ cafés
