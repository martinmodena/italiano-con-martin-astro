Quand l'utilisons-nous ?

Demandes aimables
Mi diresti il tuo nome?
Souhaits
Vorrei parlare meglio italiano.
Conseils
Dovresti leggere ogni giorno.
Hypothèses légères
Io andrei in treno, non in auto.

Très utile : pour réserver, demander une information ou parler avec politesse, le condizionale change immédiatement le ton.

Erreurs courantes

Incorrect : io vorrebbe.Corretto: io vorrei.
Incorrect : potresti aiutarmi? detto senza tono gentile.Meglio: Potresti aiutarmi, per favore?
Incorrect : noi parleriamo.Corretto: noi parleremmo.
Incorrect : loro andarebbero.Corretto: loro andrebbero.
