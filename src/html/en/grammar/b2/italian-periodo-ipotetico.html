The three main types

TypeStructureExample
Realse + presente, presente/futuroSe studi, migliori.
Possiblese + congiuntivo imperfetto, condizionale presenteSe studiassi di più, parleresti meglio.
Unreal in the pastse + congiuntivo trapassato, condizionale passatoSe avessi studiato, avresti superato l'esame.

Possible or imaginary hypothesis

We use the congiuntivo imperfetto after se and the condizionale presente in the result clause.

Se avessi tempo, leggerei di più.
Se fossi in Italia, parlerei italiano ogni giorno.
Se potessi, farei una lezione con Martin.
Se studiassimo insieme, sarebbe più facile.

Unreal hypothesis in the past

When we talk about something that did not happen, we use the congiuntivo trapassato and the condizionale passato.

Se avessi saputo...
Se avessi saputo la risposta, l'avrei detta.
Se fossi partito...
Se fossi partito prima, sarei arrivato in tempo.
With avere
avrei mangiato, avresti visto.
With essere
sarei andato, saresti arrivata.

Common mistakes

Wrong: se avrei tempo. Correct: se avessi tempo.
Wrong: se sarei ricco. Correct: se fossi ricco.
Wrong: se studiavo, parlerei. Correct: se studiassi, parlerei.
Wrong: se avrei studiato. Correct: se avessi studiato.
