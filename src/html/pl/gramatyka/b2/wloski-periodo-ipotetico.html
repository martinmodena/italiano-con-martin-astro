Trzy główne typy

TypStrukturaPrzykład
Realnese + presente, presente/futuroSe studi, migliori.

Nierealne w przeszłościse + congiuntivo trapassato, condizionale passatoSe avessi studiato, avresti superato l'esame.

Hipoteza możliwa lub wyobrażona

Po se używamy congiuntivo imperfetto, a w skutku condizionale presente.

Se avessi tempo, leggerei di più.
Se fossi in Italia, parlerei italiano ogni giorno.
Se potessi, farei una lezione con Martin.
Se studiassimo insieme, sarebbe più facile.

Hipoteza nierealna w przeszłości

Gdy mówimy o czymś, co się nie wydarzyło, używamy congiuntivo trapassato i condizionale passato.

Se avessi saputo...
Se avessi saputo la risposta, l'avrei detta.
Se fossi partito...
Se fossi partito prima, sarei arrivato in tempo.
Z avere
avrei mangiato, avresti visto.
Z essere
sarei andato, saresti arrivata.

Typowe błędy

Błędnie: se avrei tempo. Poprawnie: se avessi tempo.
Błędnie: se sarei ricco. Poprawnie: se fossi ricco.
Błędnie: se studiavo, parlerei. Poprawnie: se studiassi, parlerei.
Błędnie: se avrei studiato. Poprawnie: se avessi studiato.
